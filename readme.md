# 为 Claude Code 提供更加专业的简体中文界面

安装本扩展后，Claude Code 侧边栏的按钮、通知、对话框等全部以简体中文显示。

> 本扩展基于 [LaiYueJi/claude-code-zh](https://github.com/LaiYueJi/claude-code-zh) 修改而来，仅保留简体中文，移除简繁切换，并修正了 89 处翻译问题。现累计 **1833 条**规则，覆盖设置、权限、钩子、沙箱、记忆、插件、用量统计等对话框。

## 🚀 安装

确保已安装官方 **Claude Code for VS Code** 扩展，然后：

- **从市场安装**：在 VS Code 的扩展面板搜索本扩展并安装。

装好后依提示点击**重新加载窗口**，中文界面即可正确显示。此后，VS Code 启动时会自动套用，Claude Code 更新后也会自动重新翻译。

## 💡 日常使用

点击 VS Code 右下角状态栏 **🌏 简体中文** 按钮即可弹出菜单。

## ❗ 注意事项

本扩展基于 `laiyueji.claude-code-zh` 修改，两者解决方案相同，**请勿同时安装**——两者都会在启动时套用自己的规则，相互覆盖。
